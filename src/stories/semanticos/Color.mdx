# Color

Los colores se nombran con esta fórmula:

```
[category].[element].[role].[modifier].[state]
```

Cada uno tiene un valor para el **modo claro** y otro para el **modo oscuro**, y cada muestra enseña los dos.

En los textos, iconos, bordes y foco aparece el **contraste** con su fondo. El mínimo es 4,5:1 en el texto, 3:1 en iconos, bordes y foco, y 7:1 en `text.neutral.strong`, el de la información médica. `border.neutral.default` es solo decorativo: para los campos se usa `border.neutral.strong`.
